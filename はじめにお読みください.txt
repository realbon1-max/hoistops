HOIST OPS（PWA版）の置き方

■ このフォルダの中身
  index.html               アプリ本体（内蔵の標高データ入り。約19 MB）
  manifest.webmanifest     ホーム画面に追加したときの名前・色・アイコンの設定
  sw.js                    電波がなくてもアプリが開くようにする仕組み
  icon-*.png / apple-touch-icon.png   アイコン

  ※ 7つのファイルは必ず同じ場所に、名前を変えずに置いてください。

■ 1. インターネット上に置く（例：GitHub Pages・無料）
  1) https://github.com で無料アカウントを作る
  2) 右上「＋」→「New repository」。名前は例えば hoistops。「Public」を選んで作成
     （無料プランで GitHub Pages を使えるのは Public のリポジトリです）
  3) 「uploading an existing file」から、このフォルダの7つのファイルをまとめてドラッグして「Commit changes」
  4) 「Settings」→ 左の「Pages」→ Branch を「main」「/(root)」にして「Save」
  5) 1〜2分後、https://（アカウント名）.github.io/hoistops/ で開けるようになります

  ※ Public にすると、URLを知っている人は誰でも開けます。
     隊内だけに限りたい場合は、Cloudflare Pages ＋ Cloudflare Access（少人数なら無料）などで
     メールアドレスによるログイン制限をかけてください。
  ※ 中に飛行規程（RFM）の性能図から読み取った値・チャート画像、機体の絵、写真が入っています。
     関係者以外に公開する前に、権利の確認と差し替えをしてください。

■ 2. iPhone・iPad にアプリとして入れる
  1) Safari で上のURLを開く
  2) 共有ボタン（□↑）→「ホーム画面に追加」→「追加」
  3) ホーム画面の「HOIST OPS」アイコンから起動すると、アプリのように全画面で開きます
  4) 一度電波のある所で開いておけば、その後は電波がなくても起動します
     （地図の画像は、アプリ内の「地図を端末に保存」で保存した範囲だけ表示されます）
  5) 位置情報を聞かれたら「許可」。現在地ボタンが使えるようになります

■ 3. Android に入れる
  1) Chrome で上のURLを開く
  2) 右上「︙」→「アプリをインストール」（または「ホーム画面に追加」）

■ 4. 新しい版に入れ替えるとき
  1) 新しい index.html を GitHub に同じ名前でアップロード（上書き）
  2) sw.js の 3行目 VERSION の文字を変える（例：'hoistops-2026-10-19a' → 'hoistops-2026-11-01a'）
     これも上書きアップロード
  3) 端末でアプリを一度開き直すと、新しい版に切り替わります
     （切り替わらないときは、アプリを閉じてもう一度開く）

■ 注意
  ・訓練・計画用の目安です。運航の判断は必ず RFM の原図・最新の AIP / NOTAM・現場の状況で行ってください。
  ・入力した値（燃料・装備・描いた地点など）は、その端末のブラウザの中だけに保存されます。
    iPhone では、長い間（数週間）アプリを開かないと消えることがあります。
